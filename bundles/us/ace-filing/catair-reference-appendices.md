The CATAIR appendices are cross-chapter reference tables: code lists and
algorithms every ABI filing draws on. This bundle holds local copies of the
following (edition dates in each stub):

| Appendix | Contents | Stub |
|----------|----------|------|
| **B — Valid Codes** | Country/currency codes, EU codes, general valid values (Pub # 3913-1124) | [stub](/sources/catair-appendix-b-valid-codes.md) |
| **C — Tariff Abbreviations** | HTS units of measure and abbreviations | [stub](/sources/catair-appendix-c-tariff-abbreviations.md) |
| **D — Metric Conversion** | Inch-pound ↔ metric factors for HTS quantities | [stub](/sources/catair-appendix-d-metric-conversion.md) |
| **E — Valid Entry Numbers** | XXX-NNNNNNN-C format and the check-digit algorithm | [stub](/sources/catair-appendix-e-valid-entry-numbers.md) |

| **I — Hold Harmless Agreement** | Model agreement for CBP releasing entry data to an agent | [stub](/sources/catair-appendix-i-hold-harmless.md) |

Practical notes:

- **Entry number check digit** (Appendix E) and **duty computation codes**
  (Appendix F) are the two appendices most often implemented in filing
  software rather than merely consulted.
- Several appendices are old (2008–2016) yet still the posted editions —
  age alone doesn't mean superseded, but verify against the
  [CATAIR page](https://www.cbp.gov/trade/ace/catair) before coding to them.
- Errors on **entry summary** filings have their own dictionary outside the
  appendix lettering — see the
  [ACE Error Dictionary](/sources/catair-entry-summary-error-dictionary.md)
  cited from [Entry Summary Filing](/ace-filing/entry-summary-filing.md).
