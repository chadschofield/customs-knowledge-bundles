**Importer/Consignee Create/Update** CATAIR chapter, March 13, 2019
(Version 12, posted as draft), 54 pages. Input and output record layouts for
ABI filers to add or update name/address/identity information in the
Importer/Consignee File — the process previously handled on paper **CBP Form
5106**. The importer-of-record record this creates is a prerequisite to filing
entries; see [Right to Make Entry](/entry/right-to-make-entry.md).
