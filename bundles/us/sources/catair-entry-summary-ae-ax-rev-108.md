**Entry Summary Create/Update (AE/AX)** CATAIR chapter, **Revision 108**
(November 1, 2025), Pub # 0875-0419, 246 pages. Record formats and processing
instructions for submitting entry summary (CBP Form 7501 data) to ACE:
input structure maps, the full AE record set, line/PGA groupings, usage notes
by entry type, party and transportation reporting, and output/response
records. Rev 108 added Importer's Additional Declaration Type Code 11
(Auto Parts Offset License) and expanded SE32/SE52 looping.

At the time of writing this is the **production version** — CBP lists the
chapter as "v108" on the CATAIR page, with
[Revision 109](catair-entry-summary-ae-ax-rev-109.md) published but not yet
deployed.
