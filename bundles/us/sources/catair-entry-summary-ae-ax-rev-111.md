**Entry Summary Create/Update (AE/AX)** CATAIR chapter, "September 2026"
edition (file dated 2026-09-24 on cbp.gov), Pub # 0875-0419, 254 pages. Its
table of changes runs through **Revision 111**:

| Rev | Date | Change |
|-----|------|--------|
| 111 | 2026-07-24 / 09-08 | **Entry Type 13 (Informal – Mail)** added to AE Table 2. New **Final Delivered To Party** groupings: header 12/13-records, line 48/49-records. Input 23-record: for ET13 the Manifest Component Type Code must be **"M"** and the Issuer Code must be the **Secure Filing Postal (SFP)** code; Manifest Component Identifier widened from 12AN to **50AN**. The Bond Waiver Indicator text now notes that bonds aren't always required by regulation. |
| 110 | 2026-09-08 | **FY27 user fees** for importations from **2026-10-01**: formal MPF min **$34.58** / max **$670.86**; informal MPF (automated) **$2.77**; **Dutiable Mail Fee $7.61**; manual entry/release surcharge **$4.15**. The new amounts also apply to a summary pre-filed before 10-01 when its entry date is on or after 10-01. |
| 109 | 2026-07-16 | IAD 07/08 (aluminum/steel) barred for US-territory origins; new **IAD 12 copper smelt & cast** detail; GBI groupings repeat 4×, SE31/SE51 identifier widened from 20 to 35 characters, ALTA/Altana qualifier. The chapter notes that (A) and (B) deployed to production **2026-07-16 and 2026-07-30**; the GBI items (C)–(E) await a CSMS announcement. |

CBP scheduled the rev 111 ET13 changes for production on **2026-09-22**
(CSMS # 69915041), and the chapter moved to the *Current Capabilities*
section by 2026-09-24.
