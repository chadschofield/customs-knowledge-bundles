**Participating Government Agencies Message Set** CATAIR chapter, **Revision
28**, April 28, 2026, Pub # 0875-0419, 70 pages. The PG-record input layouts
(OI, PG01–PG60) used to submit PGA data with cargo release and entry summary
filings, plus the PGA correction capability. Rev 28 added LAT/LON qualifier
codes (PG60/PG19) and a new Inspection/Laboratory Testing Status on PG30.
