**ACE Cargo Release (SE) Input Validation Rules**, Pub # 0875-0419 — the
condition/error code dictionary for SE filings. Latest change **June 24,
2026**: added error **333 – IMPORTER OF RECORD INACTIVE FOR ENTRY** and
removed a set of codes no longer active in production (098, 119, 207, 209,
223, 242, and others). The new 333 code is enforcement plumbing for the
2025–2026 importer-of-record tightening.
